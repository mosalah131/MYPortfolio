# Mohamed Salah Portfolio
A responsive personal portfolio built from the Portfolio Building Handout structure and Mohamed Salah's CV.

## Sections
Cover / Hero, About, USP, Education, Skills, Work Experience, Services, Projects, Certifications, CTA & Contact.

## Run locally
Open `index.html` in a browser.

## Publish
This is a static site and can be deployed to GitHub Pages, Vercel, Netlify, or another static host.
